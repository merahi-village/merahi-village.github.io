Shekhpurwa

Shekhpurwa is a village that shares Merahi's own Pakari gram panchayat, within Hasanpura block, Siwan district. Like Merahi, it falls within the Daraunda assembly constituency and the Siwan parliamentary constituency, and carries the same 841240 postal code as Merahi and Dibi.

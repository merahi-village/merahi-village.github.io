# Welcome to Your Blog!

This is your first blog post. You can edit or delete it, and start writing your own posts.

## How to create new posts:

1. Create a new file in the `_posts` folder
2. Name it with the format: `YYYY-MM-DD-your-post-title.md`
3. Add front matter at the top (the content between `---`)
4. Write your post in Markdown

## Example Front Matter:

```
---
layout: post
title: "Your Post Title"
date: 2026-05-30 10:00:00 +0000
categories: category-name
---
```

That's it! Your post will automatically appear on the blog.

Happy blogging! ✍️
